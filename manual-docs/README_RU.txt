AC4 PHYSX FIX 0.3 ALPHA — РУЧНАЯ УСТАНОВКА
Нативная упаковка 0.3.1. Это альтернатива EXE, устанавливать оба варианта подряд не нужно.

ПЕРЕД УСТАНОВКОЙ
Поддерживается только исходный AC4BFSP.exe Steam (2023) с SHA-256:
bc11ad7924e1eca7363ee86aa3332c05386d0a05896c0b7370131daee9ab5150
В отличие от EXE, этот ZIP сам не проверяет версию, конфликты и доступ к папке.
Если ты не уверен в версии — используй нативный установщик с проверкой, а не ручное копирование.
Закрой игру. Сохрани резервную копию папки игры или хотя бы файлов, которые собираешься менять.

КУДА КОПИРОВАТЬ
1. Распакуй ZIP в отдельную папку, например Downloads/AC4Patch.
2. Открой папку GAME_FILES внутри распакованного архива.
3. Найди папку установленной игры: в ней находится AC4BFSP.exe.
4. В папке игры НЕ ДОЛЖНЫ уже существовать dinput8.dll, nvcuda.dll, AC4Fix или AC4-PhysX-D3D.
   Если есть хоть один — остановись. Это может быть старая версия или другой мод. Не соглашайся на замену файлов.
   Для нашей старой версии сначала используй её штатное удаление / нативный установщик.
5. Скопируй СОДЕРЖИМОЕ GAME_FILES в папку игры.
   Должно получиться:
   Игра/AC4BFSP.exe  (уже существующий файл игры; в архив он не входит)
   Игра/dinput8.dll
   Игра/nvcuda.dll
   Игра/AC4Fix/Settings.ini
   Игра/AC4Fix/install-manifest.json
   Игра/AC4-PhysX-D3D/...
   Неправильно: Игра/GAME_FILES/dinput8.dll.
6. Запускай игру обычным способом.

ВКЛЮЧЕНО ПО УМОЛЧАНИЮ
Исправления при разблокированном FPS, PhysX через Direct3D 11, производительные ядра поддерживаемых Intel.
FPS автоматически: частота монитора минус 3 (144 Гц -> 141 FPS). Это верхний лимит, не гарантированный FPS.
Дальность детализации — как в игре. Диагностика выключена.
Свои настройки записывай в AC4Fix/User.ini: те же секции и ключи, что в Settings.ini.

КАК УДАЛИТЬ
Предпочтительно: запусти AC4-PhysX-Fix-Setup.exe отдельно, выбери папку игры и нажми «Удалить патч».
Манифест из этого ZIP позволяет нативному установщику распознать ручную установку.
Перед удалением закрой игру. Изменённые настройки и журналы установщик сохранит вне папки игры.

Без EXE: удали только файлы патча, перечисленные в FILELIST_SHA256.txt, относительно GAME_FILES.
Проверь, что dinput8.dll / nvcuda.dll не были после этого заменены другим модом.
Затем удали созданные патчем журналы runtime*.log, EffectPackage*.apb из AC4Fix, а также *.log, *.csv,
crash-*.txt из AC4-PhysX-D3D, если они появились после установки. Сначала сохрани нужные журналы и User.ini.
Папки удаляй только когда они пустые; чужие и неизвестные файлы не трогай.
Оригинальный EXE, файлы игры и сохранения архив не меняет — восстанавливать их из архива не требуется.

ОГРАНИЧЕНИЯ
Это исходные игровые DLL 0.3 alpha, без изменения кода. В документации проекта проверены RTX 5090 + i9-14900K.
AMD/Intel с D3D11 заявлены, но должны быть проверены на соответствующем оборудовании.
ZIP не гарантирует прохождение антивируса или снятие карантина Nexus.
Не отключай защиту Windows ради установки.
